화면 공유창 사용 방법

Chrome 선택창이 뜨면 창 탭에서 MapleStory를 한 번 클릭한 뒤 오른쪽 아래 공유를 누르세요. 현재 사이트 탭이나 전체 화면은 선택하지 마세요. 세로 모니터에서 Windows 배율 150%를 사용하는 경우에는 위의 세로 기준을 선택하세요.

인게임 권장 화면 설정 · 가로 모니터

가로 모니터 권장 기준: 16:9 · 1920×1080 창모드입니다. 게임 창이 화면에 온전히 들어가지 않으면 1366×768(약 16:9)을 사용하세요. 화면공유에서는 MapleStory 게임 창을 선택하고 감시 영역은 공유한 게임 화면 전체로 두세요.

Chrome 확대율은 100%로 맞추세요. Windows 디스플레이 배율과 게임 내 UI 확대 배율은 별도 설정입니다. Windows 100%를 필수 조건으로 요구하지 않으며, 게임 내 UI 배율별 감지 성능은 아직 검증하지 못했습니다.

공유 해상도가 같아도 사진이나 게임 화면이 여백 속에 작게 표시되면 미탐이 생길 수 있습니다. 권장 설정이 모든 화면의 감지를 보장하지는 않습니다.

이전 OPT11 검증 기록 · 2026.10.05

공유 미리보기 끊김·분석 지연 보완

무거운 이미지 비교 작업을 분리하고 나누어 처리해, 분석 중 화면 갱신이 오래 멈추는 현상을 줄이도록 보완했습니다. 문구 분석 중 새 클릭 안내문을 확인하는 순서도 개선했습니다.

분석이 5초 이상 지연되면 ‘화면공유 연결됨 · 분석 지연’으로 표시합니다. 이 문단의 OPT11 결과는 이전 버전 기록입니다. 현재 M400-P2는 한 현재 입력 프레임의 모든 필수 최종 판정을 통과하면 1회 최종 합격으로 알립니다. 이전 성공 결과를 재사용하거나 수치 기준을 완화하는 방식이 아닙니다. 룬 알림은 기존 3회 확인을 유지합니다.

이전 OPT11에서 Chrome 사진 영상 입력을 검사한 결과, 정식·테스트 각각 감지 대상 86/86개가 5초 이내 알림 판정에 도달했고 대조 입력 40개에서 오탐은 0건이었습니다. 초기 준비 시간은 제외한 결과입니다.

실제 게임 화면공유, 노트북·4K·Windows 125% 배율 및 소리 알림은 당시 OPT11 검사에서 검증하지 못했습니다. 전체 분석이 매번 5초 안에 끝난다는 의미는 아닙니다.
